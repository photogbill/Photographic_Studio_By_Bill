# Research notes and citation checks

Section 0.5: citations in the plan were partly written from memory. Each is verified here before the code relies
on it. Status: **checked** (read and used), **used** (implemented from the published description),
**open** (not yet verified).

| Paris, Hasinoff, Kautz 2011 local Laplacian filters; Aubry et al. 2014 fast algorithm | 9.3, 22 | checked | Citation verified (ACM TOG 33(5):167, 2014, DOI 10.1145/2629645). Used for microcontrast with our own remapping function. |
| Zhuo and Sim 2011, blur from the gradient ratio of a re-blurred image | 10.5 | checked | Citation verified (Pattern Recognition 44(9):1852-1858). Effective derivative widths calibrated on synthetic edges (0.68 / 0.66 px). |
| STARRED / Firedec "deconvolve to a target PSF" (section 21 change 6) | 10.5 | used | Capture sharpening deconvolves only the kernel between the measured blur and a 0.5 px target. |

| lensfun coordinate conventions | 10.1 | checked numerically | Distortion radius 1 = half the short side of a 3:2 frame with the same diagonal x (camera crop / lens crop); ptlens includes the 1-a-b-c term. Matches lensfunpy's own Modifier to 0.16 px on a 6720 x 4480 frame. Vignetting ("pa") radius 1 = half-diagonal x (camera crop / lens crop): matches to 1e-4. |
| Zheng et al. 2008 single-image vignetting (radial gradient symmetry) | 10.2 | used (simplified) | Median radial gradient per ring instead of the full asymmetry measure. Synthetic: -0.7 and -1.5 EV corners recovered within 0.02 EV; no vignetting invented on a flat-lit scene. Cannot separate lens falloff from real light falloff, so correction stays off by default. |
| Ottosson 2020, Oklab | 9.2 | checked | Blog post of 23 Dec 2020 (bottosson.github.io/posts/oklab); now in CSS Color 4. Implemented from the published matrices via ProPhoto -> sRGB-linear -> LMS; white and sRGB red reproduce the published values (RESULTS.md). |
| He, Sun, Tang 2013, guided image filtering | 9.1 | checked | Citation verified (IEEE TPAMI 35(6):1397-1409, DOI 10.1109/TPAMI.2012.213; ECCV 2010 first). Self-guided on log luminance for Smart lighting, eps 0.25^2 in stops^2. |
| van de Weijer, Gevers, Gijsenij 2007, edge-based colour constancy (grey-edge) | 9.2 | checked | Citation verified (IEEE TIP 16(9):2207-2214). First-order grey-edge, p = 6, sigma 1, on half-size camera RGB with clipped and very dark pixels masked. Neutralises warm light by design. |
| Fritsch and Carlson 1980, monotone piecewise cubic interpolation | 9.1 | checked | Citation verified (SIAM J. Numer. Anal. 17(2):238-246, DOI 10.1137/0717021). Used through SciPy's PCHIP for the point curves. |
| He, Sun, Tang 2009 / 2011, dark channel prior | 9.1 | checked | Citation verified (CVPR 2009 pp. 1956-1963; IEEE TPAMI 33(12):2341-2353, DOI 10.1109/TPAMI.2010.168). Airlight from the brightest 0.1% of the dark channel on the whole frame (lamps excluded); omega 0.95 at amount 100; t >= 0.15. |
| Hasler and Susstrunk 2003, colourfulness | 9.2 | checked | Citation verified (Proc. SPIE 5007:87-95, DOI 10.1117/12.477378). Categories: 0 not, 15 slightly, 33 moderately, 45 averagely, 59 quite, 82 highly colourful. Auto colour aims at 45. |
| DNG Specification 1.6, camera profiles | 9.2 | used | ColorMatrix / ForwardMatrix interpolation by inverse CCT; HueSatMap and LookTable in HSV of linear ProPhoto, stored value-hue-saturation. ProfileToneCurve deliberately not applied. |
| Rother, Kolmogorov, Blake 2004, GrabCut | 9.5 | checked | Citation verified (ACM TOG 23(3):309-314, DOI 10.1145/1015706.1015720). Used as the idea for "click an object" (iterated colour models); histograms + guided filter replace GMMs + graph cut. Bai and Sapiro's geodesic segmentation was tried first and dropped (RESULTS.md). |
| van Dokkum 2001 L.A.Cosmic | 8.3 | open | Phase 3. |
| Perez, Gangnet, Blake 2003, Poisson image editing | 9.6 | used | Seamless cloning as Laplace's equation with Dirichlet boundary values; cited as the reference method by both Georgiev 2004 and Farbman et al. 2009 (read). Heal solves the membrane exactly (sparse LU) on log values. |
| Georgiev 2004, Photoshop Healing Brush: a tool for seamless cloning (ECCV workshop) | 9.6 | checked | Paper read (GIMP's heal tool cites it). Healing works multiplicatively (covariant), which is why ours is in log space; Georgiev uses a fourth-order equation for continuous derivatives at the edge. Ours is second order with a feathered edge (simpler; the feather hides the seam). |
| Farbman, Hoffer, Lipman, Cohen-Or, Lischinski 2009, coordinates for instant image cloning | 9.6 | checked, not used | ACM TOG 28(3):67. Mean-value coordinates replace the linear solve; not needed while the sparse solve takes milliseconds per spot. |
| Lindeberg 1998, feature detection with automatic scale selection | 9.6 | checked | IJCV 30(2):79-116, DOI 10.1023/A:1008045108935. Dust finder: difference of Gaussians over a pyramid (scale-space blob detector) with a Hessian roundness check; a blob of width b peaks at scale b/sqrt(3), which sets the spot radius. |
| Shafaei, Little, Schmidt 2021, AutoRetouch (WACV, pp. 990-998) | 9.6 | checked | Finds that automatic tools "blindly" smooth skin and destroy its texture; professional retouching changes few pixels. Basis for keeping the pore layer untouched in Smooth skin. Their FFHQR dataset is CC BY-NC-SA and is not used. |
| Liang, Jin, Li 2014, facial skin beautification using adaptive region-aware masks | 9.6 | checked | IEEE T-Cybernetics 44(12):2600-2612. Edge-preserving layer decomposition (smoothness, lighting, colour) plus region masks: the model for Smooth skin as a mask adjustment with guided-filter layers. Liang et al. 2015 (CGF 34(7):203-212) extends it with edge-aware PDE masks. |
| Fredembach, Barbuscia, Susstrunk 2009; Susstrunk, Fredembach, Tamburrino 2010 | 9.6 | checked, not usable | Visible base layer + near-infrared detail layer gives realistic skin smoothing (79% of museum visitors preferred it). Needs an IR-converted camera; supports the base/detail approach. |
